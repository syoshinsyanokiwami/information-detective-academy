教材を公開する

おすすめは Cloudflare Pages の直接アップロードです。今回の教材はHTML・CSS・JavaScriptだけで動き、ビルドやデータベースは不要です。以下は2026年11月5日に公式資料を確認した内容です。料金・上限・画面名は変更される場合があります。

Cloudflare Pages：継続利用におすすめ

無料プランあり。今回の小規模教材に十分な容量です。フォルダーまたはZIPを直接アップロードできます。直接アップロードで作ったプロジェクトを後からGit連携へ切り替えることはできません（新規プロジェクトで作り直し）。

  1. Cloudflareアカウントを作成し、Workers & Pagesを開く。
  2. Pagesの作成から、ファイルをアップロードする選択肢を選ぶ。
  3. プロジェクト名を決め、配布ZIPをアップロードする。展開したフォルダーでも可。
  4. デプロイを実行し、表示された pages.dev のURLを各タブレットで開く。
  5. 更新時は同じプロジェクトで新しいデプロイを作り、ファイル一式を再アップロードする。

公式の直接アップロード手順 ／ 無料プラン等の上限

GitHub Pages：教材を継続的に編集する人向け

GitHub Freeでは公開リポジトリで利用可能。コードの変更履歴を残せます。教材のソースも公開されます。

  1. GitHubで公開リポジトリを作成する（例：info-detective）。
  2. ZIPを展開し、中の全ファイルをリポジトリ直下へアップロードして保存する。index.htmlを直下に置く。
  3. Settings → Pages → Build and deploymentでDeploy from a branchを選ぶ。
  4. mainブランチと / (root) を選んでSave。
  5. 公開処理の完了後、表示されたURLを開く。更新は同じファイルを変更して保存する。

公式のサイト作成手順

Netlify：手軽なフォルダー公開

無料プランは月300クレジット。公開・通信などが消費対象なので使用量を確認してください。定額無制限ではありません。

  1. 無料アカウントを作り、手動デプロイ（drag and drop）を選ぶ。
  2. ZIPを展開し、index.htmlが入っているフォルダーをドロップする。
  3. 作成されたプロジェクトのURLを開き、公開状態を確認する。
  4. 更新時は同じプロジェクトのデプロイ画面へ更新済みフォルダーをドロップする。

公式のデプロイ手順 ／ 料金・利用枠

tiiny.host：短時間で試すときに

無料枠は1プロジェクト、アップロード3MB、月5,000訪問・5GB通信。今回のZIPはこの容量内です。無料版にはブランド表示があり、非表示は有料です。

  1. tiiny.hostでサイトのアップロードを選ぶ。
  2. 配布ZIPを指定し、リンク名を決める。
  3. 案内に従ってアカウント確認と公開を行い、URLをタブレットで開く。
  4. 更新は管理画面で同じプロジェクトのファイルを差し替える。

公式の無料枠・対応ファイル ／ 料金表

共通の確認

  • index.htmlと各HTML・JavaScript・CSS、QR画像、assetsフォルダーを、配布されたフォルダー構成のまま置きます。ZIPを開いてすぐindex.htmlが見える構成です。
  • 公開先を変えるとブラウザー保存の進捗は引き継がれません。
  • 学校のWi-Fiで公開URLにアクセスできるか事前確認。教師用ページと解答も閲覧可能です。
  • QRカードには公開URLが入っていないので、公開先が変わっても同じカードを使えます。
  • 外部ライブラリーや外部画像を読み込まない教材です。PCでは展開後にindex.htmlを開いて試せます。タブレットではHTTPS公開を推奨。オフライン専用アプリではありません。
